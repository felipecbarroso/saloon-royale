# Saloon Royale

Duelo de pistoleiros para até 8 jogadores.

## Baixar

**[Baixar o jogo (SaloonRoyale.zip)](https://github.com/felipecbarroso/saloon-royale/releases/latest/download/SaloonRoyale.zip)**

1. Baixe o zip, clique com o botão direito e escolha **Extrair tudo**.
2. Abra o **Saloon Royale.exe** que está na pasta extraída.
3. O jogo se atualiza sozinho quando sai uma versão nova.

Para jogar pela internet com os amigos, use o Radmin VPN. As instruções estão no LEIAME.txt dentro do zip.
